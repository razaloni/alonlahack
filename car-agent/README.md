# 🚗 סוכן חיפוש רכב

כל 3 שעות הסוכן סורק כמה אתרי מודעות ושולח **מייל** עם **קישור** לכל רכב חדש שמתאים לך. אפשר להוסיף גם טלגרם.

## 🌐 איפה הוא מחפש
| מקור | איך |
|---|---|
| יד2 | פענוח מדויק של נתוני האתר |
| הומלס, WinWin, iCar | זיהוי מודעות לפי טקסט (מחיר ₪ + שנתון). **ניסיוני** |
| 🔎 **כל אתר אחר ברשת** | בכל הרצה הסוכן מחפש במנוע חיפוש (3 שאילתות, ברוטציה). הוא פותח כל תוצאה: אם יש בה כמה מודעות, הוא **זוכר את האתר** וסורק אותו מעכשיו בכל הרצה. אם זו מודעה בודדת, היא נבדקת מול הסינונים. אתר שנכשל 3 פעמים ברצף יורד מהרשימה |
| פייסבוק Marketplace וקבוצות | ❌ לא נתמך. דורש התחברות, ופייסבוק אוסרת סריקה אוטומטית |

**מנוע החיפוש:** ברירת המחדל היא DuckDuckGo, בלי צורך במפתח, אבל הוא עלול לחסום בוטים. לחיפוש יציב יותר אפשר להוסיף סוד בשם `BRAVE_API_KEY` (מפתח ל-Brave Search API).
אפשר לשנות את שאילתות החיפוש ולחסום אתרים ב-`config.json`, תחת `discovery`.

כל מייל מסתיים ב"📡 מצב הסריקה", שמראה מה עבד בכל אתר. אם אף אתר לא עבד, תקבל מייל אזהרה (לכל היותר פעם ביום).

## ✅ הפעלה ב-3 צעדים

**1. יוצרים סיסמת אפליקציה ב-Gmail (5 דקות)**
- נכנסים ל-myaccount.google.com ← אבטחה ← מפעילים **אימות דו-שלבי** (אם עוד לא מופעל)
- מחפשים בהגדרות החשבון "סיסמאות לאפליקציות" ויוצרים סיסמה בשם `car-agent`
- מעתיקים את הסיסמה (16 תווים)

**2. שומרים סודות ב-GitHub**
Settings ← Secrets and variables ← Actions ← New repository secret:
- `GMAIL_USER`: כתובת ה-Gmail שלך
- `GMAIL_APP_PASSWORD`: הסיסמה מצעד 1
- (רשות) `ALERT_EMAIL_TO`: אם רוצים לקבל את ההתראות לכתובת אחרת
- (רשות, לטלגרם) `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`

**3. ממזגים את הענף ל-`main`**
GitHub מריץ תזמונים רק מהענף הראשי. אחרי המיזוג: **Actions** ← **Car search agent** ← **Run workflow**.

## 💡 טיפים
- **יד2:** מסננים באתר עצמו, מעתיקים את כתובת הדף ומדביקים אותה ב-`search_urls`.
- **אתר נוסף:** מוסיפים שורה ב-`other_sources` עם שם וכתובת של דף תוצאות.
- **פייסבוק:** כדאי להפעיל שם ידנית התראה על חיפוש שמור ב-Marketplace.

## ⚠️ חשוב לדעת
- ליד2 יש מערכת חסימת בוטים. אם הלוג ב-Actions מציג `BLOCKED`, הסריקה נחסמה ולא נשלחה התראה.
- הסינון מתבסס על מה שכתוב במודעה. מוכר יכול לכתוב "פרטי" גם כשהרכב היה בליסינג.
- **לפני קנייה:** לבדוק את היסטוריית הבעלות לפי מספר רישוי באתר משרד התחבורה ולעשות בדיקת מוסך.
