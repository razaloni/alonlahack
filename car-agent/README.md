# 🚗 סוכן חיפוש רכב

סורק את **יד2** כל 3 שעות ושולח לך הודעה (טלגרם ו/או מייל) עם **קישור** לרכבים חדשים שמתאימים.

## מה הוא מחפש (אפשר לשנות ב-`config.json`)

| דרישה | הגדרה |
|---|---|
| 💰 מחיר | 7,000–20,000 ₪. מתחת ל-15,000 ₪ מקבל ניקוד מלא |
| ⚙️ גיר | אוטומטי בלבד |
| 📅 שנתון | 2009 ומעלה. חדש יותר = ציון גבוה יותר |
| 🛣️ ק"מ | עד 220,000. פחות = ציון גבוה יותר |
| 👤 מוכר | פרטי בלבד, בלי סוחרים ובלי מודעות מקודמות |
| 🚫 נפסלים | מודעות שמופיעות בהן המילים ליסינג / השכרה / מימון / שעבוד / מעוקל |
| 🔧 טיפולים | בונוס אם המודעה מזכירה טיפולים או ספר טיפולים |
| 👨‍👩‍👧 משפחתי | בונוס לדגמים משפחתיים ובינוניים (קורולה, מאזדה 3, i30, אוקטביה...) |

## ✅ הפעלה ב-3 צעדים

**1. יוצרים בוט טלגרם (5 דקות)**
- בטלגרם פותחים את `@BotFather` ← שולחים `/newbot` ← מעתיקים את ה-**token**
- שולחים לבוט החדש הודעה כלשהי
- פותחים בדפדפן `https://api.telegram.org/bot<TOKEN>/getUpdates` ומעתיקים את המספר שמופיע ב-`"chat":{"id": ...}`

**2. שומרים סודות ב-GitHub**
Settings ← Secrets and variables ← Actions ← New repository secret:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- (רשות, למייל) `GMAIL_USER`, `GMAIL_APP_PASSWORD` (סיסמת אפליקציה של Google, לא הסיסמה הרגילה)

**3. ממזגים את הענף ל-`main`**
GitHub מריץ תזמונים אוטומטיים רק מהענף הראשי. אחרי המיזוג: לשונית **Actions** ← **Car search agent** ← **Run workflow** להרצה ראשונה.

## 💡 טיפ: לסנן ישירות באתר
אפשר לסנן ביד2 עצמו (גיר אוטומטי, שנתון, ק"מ, סוג רכב), להעתיק את כתובת הדף ולהדביק אותה ב-`search_urls` בקובץ `config.json`.

## ⚠️ חשוב לדעת
- ליד2 יש מערכת חסימת בוטים. אם הלוג ב-Actions מציג `BLOCKED`, הסריקה נחסמה ולא נשלחה התראה.
- הסינון מתבסס על מה שכתוב במודעה. מוכר יכול לכתוב "פרטי" גם כשהרכב היה בליסינג.
- **לפני קנייה:** לבדוק את היסטוריית הבעלות לפי מספר רישוי באתר משרד התחבורה ולעשות בדיקת מוסך.
